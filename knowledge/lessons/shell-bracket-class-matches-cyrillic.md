# Урок: скобочный класс в shell совпадает с кириллицей

## Что произошло

В лаунчере АРХИ меню отрабатывало один раз и выходило, сколько бы человек
ни отвечал «нет» на «Вернуться в меню?». Разбор вывел к строке:

```sh
case "$OTVET" in
    [нНnN]*) exit $KOD ;;     # «нет» — выйти
esac
```

«д» (да) уходило в ветку выхода вместе с «н». Хуже того: тем же приёмом
спрашивалось согласие на **скачивание и запуск постороннего установщика
Python** и на установку средств проверки:

```sh
case "$OTVET" in
    [дДyY]*) skachat_i_zapustit ;;   # «н» сюда тоже попадает
esac
```

То есть **отказ читался как согласие** на действие, которое человек вправе
не разрешить на своей машине.

## Почему это случилось

В C/POSIX-локали (а лаунчер запускается именно так) сопоставление
в `case` идёт **побайтно**. Кириллица в UTF-8 двухбайтная, и **все** буквы
начинаются с `0xD0` либо `0xD1`:

```
д = D0 B4      н = D0 BD      Д = D0 94      Н = D0 9D
```

Скобочный класс `[дДyY]` раскрывается в набор байтов `{D0, B4, 94, y, Y}`
и диапазоны между ними. Первый байт «н» — `D0` — в наборе есть, а `*` после
класса берёт остаток. Совпадает **любая** кириллическая буква.

Признак, по которому это ловится глазом: **скобочный класс, внутри которого
есть хоть один не-ASCII символ.**

## Как починили

Классы заменены на перечисление образцов — оно сравнивает строки целиком,
а не байты поодиночке:

```sh
case "$OTVET" in
    н*|Н*|n*|N*) exit $KOD ;;
esac
```

И сторож, который не даёт приёму вернуться:

```python
def test_soglasie_ne_sveryaetsya_skobochnym_klassom():
    for klass in re.findall(r"\[[^\]]+\]", starter):
        assert klass.isascii(), (
            f"скобочный класс {klass} с кириллицей сравнивает байты: "
            "в C-локали все русские буквы начинаются с 0xD0")
```

`ARCHI-NSU/tests/test_launchery.py`.

## Чтобы не повторилось

- **Не-ASCII внутри `[...]` в shell — всегда ошибка.** Перечислять через `|`.
- **Умолчание у опасного действия — запрет.** Даже с верным сравнением
  ветка «согласие» не должна быть той, куда попадает неразобранный ввод.
  Правильная форма: явно проверить согласие, всё остальное — отказ.
- Ошибка **асимметрична по цене**: в вопросе «вернуться в меню?» она стоит
  неудобства, в вопросе «скачать и запустить установщик?» — исполнения
  постороннего кода. Спросы о согласии перечитывать отдельно от прочего кода.
- То же касается `[[:alpha:]]` и диапазонов `[а-я]` — в C-локали они
  не означают того, что читаются.
- В батниках Windows этой ловушки нет (сравнение строковое,
  `if /i "%OTVET:~0,1%"=="n"`), но есть своя: кириллица в консоли cp866
  не совпадёт с латиницей вовсе — поэтому лаунчер там весь транслитом.
