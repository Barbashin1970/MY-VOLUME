# Урок: «якорь есть, а перехода нет»

> Контекст: РАГРАФ, страница `/documentation` — разборщик Markdown на сервере
> (`backend/app/services/docs_markup.py`) отрисовывает документы и книги, браузер
> печатает их в PDF. Те же файлы читают на GitHub и в редакторе.

## Что произошло

Владелец попросил оглавление с переходами в пособии на 7 400 строк. В книге
33 раздела второго уровня и 226 третьего. Почти в каждом спринте есть свой
«Главное за минуту», «О чём эта часть» и «Ключевые термины». Ссылки оглавления
пишутся один раз, а работать должны в трёх местах: на GitHub, на странице
изделия и в PDF, сохранённом с неё.

Разборщик страницы строил якоря своим правилом, и с GitHub оно расходилось
в четырёх местах:

| | GitHub | было на странице |
|---|---|---|
| «Блок C — итоги» | `блок-c--итоги` (каждый пробел — дефис) | `блок-c-итоги` (пробелы схлопнуты) |
| «📋 Чек-лист» | `-чек-лист` | `чек-лист` (края обрезаны) |
| второй «Главное за минуту» | `главное-за-минуту-1` | `главное-за-минуту-2` |
| «`test_dym`» | `test_dym` | `test-dym` |

Ссылка, написанная под GitHub, на странице ни к чему не вела. Клик молча ничего
не делал — ни ошибки, ни признака.

## Почему это случилось

Правило якорей скопировали вместе с разборщиком из донорского проекта, где
ссылок «#…» почти не было. До книг расхождение не проявлялось: внутренние ссылки
были только в одном документе (29 штук), и все они попадали в заголовки без тире
и без повторов.

## Как починили

Коммит `417592a` от 31.10.2026 (РАГРАФ).

- `_yakor` повторяет github-slugger: строчные буквы; убирается всё, кроме букв,
  цифр, «_», «-» и пробела; **каждый** пробел — дефис; повтор получает «-1», «-2»;
  у ссылки внутри заголовка в якорь идёт текст, а не адрес.
- Оглавление собирает скрипт `scripts/oglavlenie_knigi.py`, якоря он берёт
  у того же разборщика. Два расчёта одного якоря разойтись не могут.
- Перед сменой правила проверили, что 29 прежних ссылок разрешаются по обоим
  правилам, — сломать было нечего.

## Чем обнаружено

Сторожем до выкладки. Его видели красным: на прежнем правиле не разрешились
ссылка на заголовок с тире и десятки разделов с повторяющимися именами.

## Чтобы не повторилось

- **Markdown читают в нескольких местах — правило якорей одно, GitHub-овское.**
  Своё правило имеет смысл, только если файлы нигде больше не открывают.
- **Оглавление большой книги руками не пишут.** Его собирает скрипт по заголовкам,
  а сторож сверяет множества «разделы ↔ ссылки оглавления»: новый раздел
  в рукописном оглавлении просто не появляется.
- **Сторож: каждая ссылка «#…» ведёт к заголовку этого документа.** Для перехода
  в другой документ — к заголовку того документа. Мёртвый якорь не виден
  никому, кроме того, кто по нему кликнул.
- **Нумерацию повторов считают по всем заголовкам документа.** Заголовок внутри
  цитаты или setext-заголовок («текст» над строкой `---`) один отрисовщик
  посчитает, а другой нет — и «-3» поедет. Это проверяют перед сборкой оглавления.
