# Урок: «оба числа с командой, а правы не оба»

> Контекст: РАГРАФ, 31.10.2026. В документах каждое число пишется вместе с командой,
> которой оно получено. Пособие системного аналитика сверено с изделием 30.10.2026,
> описание программы РАГРАФ-ФРЕЙМ-13 — 31.10.2026.

## Что произошло

Сверка словаря свела рядом два документа:

| Документ | Команда | Обработчиков |
|---|---|---|
| Пособие | `grep -rE "@router\.(get\|post\|put\|patch\|delete)" backend/app/api \| wc -l` | 252 |
| РАГРАФ-ФРЕЙМ-13 | `grep -h '^@router\.' backend/app/api/*.py \| wc -l` | 251 |

Обе команды честные и повторяемые. Каждый документ по отдельности выглядит
сверенным.

## Почему это случилось

В `backend/app/api/kappa.py:299` есть строка документации вспомогательной
функции с примером «будущего» обработчика:

```python
    """Внутренний helper для пробрасывания запросов в Каппу с JWT.

    Использование (будущие endpoint'ы):
        @router.post("/kappa/verify/{dataset_id}")
```

Команда без `^` нашла этот пример. Декоратор настоящего обработчика стоит
в первой колонке, пример — с отступом внутри строки документации. grep смыслов
не различает: для него это одинаковые строки.

## Как починили

- **Пособие.** Число и команда исправлены на привязанные: 251 и
  `grep -rhE "^@router\.(get|post|put|patch|delete)" backend/app/api | wc -l`.
  Правка записана в «Что нового в редакции 2».
- **Справочник** берёт ту же команду, что описание программы. Коммит `47f0419`.

## Чтобы не повторилось

- **Конструкции кода считать привязанным образцом или по AST.**
  - `^@router\.` — декоратор на уровне модуля.
  - `^def test_` — проверка, но без методов классов: их отступ четыре пробела.
  - Надёжнее всего — `ast`: строки документации и комментарии ему не видны.
- **Два числа для одного утверждения — повод сравнить совпадения, а не выбрать.**
  Выведи оба списка (`grep -n …`), сравни их — разница покажет, кто прав:

  ```
  diff <(grep -rn 'A' …) <(grep -rn 'B' …)
  ```

  Здесь разница была ровно в одну строку, и строка эта — пример.
- **Сверяя книгу с изделием, сверяй и её числа с числами соседних документов.**
  Каждый документ по отдельности был «сверен»: расхождение видно, только если
  положить их рядом.
