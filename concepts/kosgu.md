# КОСГУ

**Классификация операций сектора государственного управления** —
российская бюджетная номенклатура. Любой грант, госконтракт, проект
в государственном НИИ / университете ведётся **не одной суммой**, а
с разбивкой по статьям расходов КОСГУ.

## Главные статьи (для IT-проектов)

| Ст. | Название | Что туда идёт |
|-----|----------|---------------|
| **211** | Заработная плата | З/п штатных сотрудников проекта |
| **213** | Начисления на оплату труда | Страховые взносы (~30% от 211) |
| **222** | Транспортные услуги | Командировки, такси |
| **226** | Прочие услуги | **Сюда идут ИП-договоры, аутсорс, патентные пошлины, регистрация ПО** |
| **310** | Приобретение основных средств | Серверы, ноутбуки > 100к₽ |
| **320** | Приобретение нематериальных активов | Лицензии на ПО, БД |
| **340** | Приобретение материалов | Расходники, бумага, картриджи |

## Зачем это знать разработчику

| Сценарий | Что важно знать |
|----------|-----------------|
| Делаешь Устав проекта по [09-charter-reports](../docs/playbooks/09-charter-reports-growth.md) | Бюджет разбивается по КОСГУ, не одной строкой |
| Подаёшь грант (РНФ, РФФИ, СНТР) | КОСГУ-разрез обязателен в смете |
| Работаешь в НГУ / НГТУ / институте | Бухгалтерия работает с КОСГУ |
| Строишь систему типа LEYKA для грантовой отчётности | Нужна сущность `ProjectBudgetItem` со столбцом `kosgu_code` |

## Применение в LEYKA

> «Бюджет проекта в Уставе разнесён по КОСГУ (а не одна сумма).
> Бухгалтерия НГУ работает именно с КОСГУ-разрезом».
> *(`~/LEYKA/docs/SKILL-PROJECT-CHARTER-AND-REPORTS.md` §1.3)*

В LEYKA планируется сущность `ProjectBudgetItem`:
```python
class ProjectBudgetItem(Base):
    id: Mapped[UUID]
    project_id: Mapped[UUID]
    kosgu_code: Mapped[str]      # "211", "213", "226", ...
    amount_allocated: Mapped[Decimal]
    amount_spent: Mapped[Decimal]
    description: Mapped[str | None]
```

Это даёт **автоматическую генерацию Устава §8** (таблица КОСГУ) и
Отчёта.

## Что не КОСГУ

- **ОКВЭД** — классификатор видов экономической деятельности.
- **ОКПД** — классификатор продукции.
- **БСК / БК** — бюджетная классификация в целом (КОСГУ — её часть).
