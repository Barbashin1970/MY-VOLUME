# meetings/

Заметки со встреч. Помогают не забыть договорённости и быстро ввести
Claude в контекст: «прочитай последние 5 встреч по проекту X».

---

## Структура

Подпапки по месяцам — `YYYY-MM/`:

```
meetings/
├── README.md
├── 2026-05/
│   ├── 2026-05-26-leyka-kanban-review.md
│   └── 2026-05-28-ragraf-arch-sync.md
└── 2026-06/
    └── …
```

## Имя файла

`YYYY-MM-DD-проект-тема.md`. Дата — ISO, проект и тема — kebab-case.

## Что писать

См. [../templates/meeting.md](../templates/meeting.md).

Минимум:

1. **Цель** — зачем встреча. Если её нет — это не встреча, это болтовня.
2. **Участники** — список (frontmatter).
3. **Решения** — что договорились.
4. **Action items** — кто что делает и до когда. **С чек-боксами.**
5. **Связь с проектом** — ссылка на `projects/<x>/`.

## Что **не** писать

- Дословный транскрипт. Это распечатка, не заметка.
- Цитаты людей в негативном свете. См. [../people/README.md](../people/README.md).
- Решения, которые на самом деле никто не подтвердил. Лучше пометить
  «обсуждалось, не решено».

## Поток в knowledge

| Что родилось на встрече | Куда уходит |
|------------------------|-------------|
| Системное решение | [docs/decisions/](../docs/decisions/) |
| Новый термин | [concepts/](../concepts/) |
| Полезный приём от коллеги | [knowledge/skills/](../knowledge/skills/) или [knowledge/patterns/](../knowledge/patterns/) |
| Конкретная задача | `projects/<x>/backlog.md` |
| Обещание перезвонить | `meetings/.../...md` + календарь, не сюда |

## Поиск встреч через Claude

«Что мы решили по канбану в LEYKA?» — Claude читает все meetings/ с
`tags: [project/leyka]`, агрегирует решения. Поэтому правильные теги важны.
