# Bartle-психотипы

**4 типа игроков** по Ричарду Бартлу (1996, MUD-исследование). Идея
обобщилась далеко за пределы игр — на любой продукт, где есть выбор
способа взаимодействия.

## 4 типа на двух осях

```
              ДЕЙСТВИЕ
                 ▲
                 │
    Killers ─────┼───── Achievers
    (давят на    │    (выполняют
     других)     │     задачи)
                 │
  ◄──────────────┼──────────────►
  ИГРОКИ         │      МИР
                 │
  Socializers ───┼───── Explorers
  (общаются)     │   (изучают)
                 │
                 ▼
            ВЗАИМОДЕЙСТВИЕ
```

| Тип | Что мотивирует | Признаки в продукте | Чего боятся |
|-----|---------------|---------------------|-------------|
| **Killers** (~1%) | Доминирование над другими | Лидерборды, PvP, рейтинги, конкуренция | Уравниловка |
| **Achievers** (~10%) | Прогресс, выполнение целей | Уровни, достижения, бейджи, статистика | Бесцельность |
| **Socializers** (~80%) | Общение, отношения | Чаты, профили, сообщества, реакции | Одиночество в продукте |
| **Explorers** (~10%) | Понимание системы | Скрытые механики, секреты, документация, API | Песочница без глубины |

**Главный сюрприз:** большинство людей — **Socializers**. Но
продуктовые команды (= Achievers + Explorers) проектируют **для
себя** и забывают про социальный слой.

## Применимость за пределами игр

| Продукт | Где Bartle помогает |
|---------|---------------------|
| **GitHub** | Achievers (зелёные квадратики), Explorers (open-source), Socializers (followers, discussions). Killers слабо представлены — отсюда токсичность редка. |
| **LinkedIn** | Achievers (карьерные тайтлы), Socializers (connections), Killers (рейтинги). Explorers — почти нет. |
| **Stack Overflow** | Achievers (репутация), Explorers (вопросы), Killers (close-голосования). |
| **Wikipedia** | Explorers (читают), Achievers (правят, копят правки). |

## Применение в твоих проектах

| Проект | Главный тип | Сценарий |
|--------|------------|----------|
| **SOFIA** | **Explorers** (любят разбираться) + **Socializers** (делятся результатами «я по нумерологии…»). Killer/Achiever почти нет — это не соревнование. |
| **GONKA** | **Killers** + **Achievers** — гоночная игра, рейтинги, время прохождения. |
| **KNIFFEL** | **Achievers** (счёт) + **Socializers** (играть с друзьями). |
| **POLINOM** | **Explorers** (научные люди) + **Achievers** (метрики JMH). |
| **LEYKA** | **Achievers** (закрыли спринт, закрыли год). Socializers слабо. |
| **RAGRAF** | **Explorers** (онтологии, граф) + **Achievers** (метрики соответствия регламенту). |

## Как использовать на этапе исследования

1. На спринте 3 (UX-исследования) — пытаешься понять не только **JTBD**,
   но и **какой тип пользователя** перед тобой. Это меняет дизайн.
2. На спринте 6 (прототипирование) — закладываешь интерфейс для
   **доминирующего типа** + минимум для остальных трёх.
3. На спринте 8 (маркетинг) — выбираешь каналы по типу: Socializers
   ловятся в соцсетях, Achievers — в профессиональных сообществах,
   Explorers — в технических блогах и Reddit.

## Антипаттерны

❌ **«Все мои клиенты — Achievers»** — это потому что **ты** Achiever
и слышишь себе подобных. Сегмент Socializers не любит писать отзывы.

❌ **Проектировать только под Killers** — токсичный продукт. Killers
шумные, но их меньшинство.

❌ **Жёстко делить пользователей на 4 ящика** — реально это спектр,
у одного человека разные типы доминируют в разных контекстах.
