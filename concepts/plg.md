# PLG — Product-Led Growth

**Стратегия, в которой главный канал привлечения, активации и
расширения — сам продукт, а не отдел продаж или маркетинга.**
Термин закреплён OpenView (2017), но принципы старше — Dropbox,
Slack, Figma, Notion.

## 3 типа компаний по источнику роста

| Модель | Главный канал | Цикл сделки | Пример |
|--------|--------------|-------------|--------|
| **Sales-led** | Менеджеры продаж | Месяцы | Oracle, SAP |
| **Marketing-led** | Реклама → лид → менеджер | Недели | Salesforce, HubSpot |
| **Product-led (PLG)** | Бесплатный/триал-продукт → платный план | Дни-часы | Figma, Notion, Slack, Vercel |

## 3 стадии PLG-цикла

```
┌────────────┐    ┌──────────────┐    ┌──────────────┐
│ Onboarding │ →  │ Activation   │ →  │ Expansion    │
│ Привёл     │    │ Получил      │    │ Привёл       │
│ нового     │    │ ценность     │    │ команду,     │
│ пользоват. │    │ за минуты    │    │ платит больше│
└────────────┘    └──────────────┘    └──────────────┘
```

### Onboarding — первая минута

Пользователь должен **дойти до aha-moment без помощи человека**:

- Регистрация через 1 клик (OAuth, Google)
- Не требует кредитной карты на входе
- Демо-данные / шаблоны / онбординг-тур
- **Time to Value (TTV) < 5 минут**

### Activation — первая ценность

Целевое действие, которое доказывает: продукт работает.

- Figma: создал и опубликовал первый файл
- Slack: отправил первое сообщение в команду
- Notion: создал первую страницу с контентом
- Dropbox: загрузил первый файл с двух устройств

**Это — критическая метрика.** Без активации Retention падает в ноль.

### Expansion — расширение

Платная конверсия + рост внутри клиента (per-seat / по фичам):

- Один пользователь → пригласил команду → каждый seat платный
- Базовый план → upgrade на Pro
- Через сетевые эффекты (виральность): чем больше пользователей, тем ценнее продукт

## Что делает продукт PLG-friendly

| Признак | Пример |
|---------|--------|
| **Self-serve onboarding** | Без созвона, без менеджера |
| **Бесплатный план или триал** | Freemium, time-limited trial |
| **Сетевой эффект** | Чем больше в команде — тем ценнее |
| **Низкая стоимость переключения** | Импорт/экспорт данных открыт |
| **Время до ценности < 5 минут** | Пользователь видит результат сразу |
| **Telemetry-driven product** | Команда видит, где пользователи отваливаются |

## Когда PLG **не** работает

- **Сложный B2B-enterprise** (ERP, CRM с миллионами полей) — нужна интеграция и обучение.
- **Регулируемые отрасли** (медицина, банки) — продукт нельзя «попробовать» без договора.
- **Дорогой продукт** ($10K+/год) — корпоративный закуп не идёт через self-serve.
- **Госзаказ** — продукт диктуется тендером.

## Применение в твоих проектах

| Проект | PLG-применимость |
|--------|------------------|
| **SOFIA** | **Идеально PLG.** Пользователь приходит → вводит дату рождения → получает рецепт. TTV = 1 минута. Activation = получил персональный профиль. Expansion = поделился в соцсетях (виральность). |
| **AI-SKLAD** | Возможен PLG для малого бизнеса. Залил CSV → получил отчёт. Платный план за объём данных. |
| **RAGRAF** | **Не PLG.** B2B-enterprise, ТЭО, договоры. Sales-led. |
| **LEYKA** | Внутренний — PLG-цикла нет, но **принципы** (low TTV, self-serve onboarding) применимы для адаптации новых сотрудников. |
| **GONKA, KNIFFEL** | По духу PLG — играешь сразу, делишься скриншотами. |

## Метрики PLG

- **TTV** (Time to Value) — от регистрации до aha-moment
- **PQL** (Product Qualified Lead) — пользователь активировался + использует продукт = тёплый лид
- **Activation rate** — % дошедших до aha от пришедших
- **Net Revenue Retention (NRR)** — рост выручки внутри существующих клиентов (главная метрика expansion)

## Антипаттерны

❌ **Требовать кредитную карту при регистрации** — убивает onboarding.

❌ **Бесплатный план без ценности** — пользователь не активируется, не понимает, зачем платить.

❌ **PLG без telemetry** — нельзя оптимизировать onboarding не зная, где люди отваливаются.

❌ **PLG + сложный enterprise-продукт** — не сочетается. Либо одно, либо другое.
