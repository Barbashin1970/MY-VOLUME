# Pattern: Claim-the-Layer Positioning

Приём позиционирования сложного технического продукта в hero лендинга / на
первом слайде питча: вместо «маршрута» или списка фич — **заявить СЛОЙ**
(«операционная система …»), вынести категорию в **eyebrow**, а H1 оставить
коротким глаголом-результатом. Выведен из разбора лидеров отрасли (Palantir
Foundry, Databricks, Camunda, Temporal, Node-RED, n8n, Microsoft Foundry),
2026-06-16.

## Проблема

Слоган сложного продукта часто пытается уместить в одну строку категорию +
охват + «поэзию» — и не делает ни одного. Пример антипаттерна: «От стройплощадки
до управления городом» — это описание путешествия, без глагола, без актора, без
доказательства, сужает к одной вертикали и недооценивает ядро. Читатель не
понимает ни *что это*, ни *насколько это серьёзно*.

## Решение (идея)

Семь ходов, как серьёзные платформы передают значимость (бери нужные):

1. **Two-tier labeling.** Смелую КАТЕГОРИЮ/СЛОЙ — в eyebrow/ярлык; H1 —
   простой уверенный глагол-результат. («THE Databricks Platform» + «Build and
   run … on your data».)
2. **Заяви СЛОЙ, а не фичу.** Позиционируйся как субстрат, на котором всё
   работает: «операционная система …», «foundation», «runs on …». Метафоры: ОС,
   фабрика/кузница, фундамент, canvas. (Palantir: *operating system for the
   modern enterprise*.)
3. **Возвысь и назови собственную абстракцию.** Дай ядру имя и роль «сердца»
   (Palantir → Ontology, Temporal → durable execution, Databricks → lakehouse).
4. **Назови акторов, которых координируешь** — делает «платформу» конкретной
   (Camunda: «agents, people, and systems»).
5. **Trust-глагол рядом с build-глаголом.** В эпоху ИИ доверие — ось, не мелкий
   шрифт («build, ground, govern»; «you can see and control»). Если объяснимость
   структурна — заявляй **«проверяемых/доказуемых» (provable)**, а не «auditable».
6. **Lineage вместо логотипов.** Нет известных клиентов — подставь **наследие**
   (научную школу, происхождение технологии) как субстрат доверия. Тот же эффект
   «за этим стоит что-то серьёзное», что у Temporal даёт стена логотипов.
7. **Outcome-first, абстракция — второй.** H1 — конкретный глагол; грандиозная
   абстракция уходит в подзаголовок/ниже.

## Диаграмма

```
┌──────────────────────────────────────────────┐
│ EYEBROW: <категория/слой>  ← смелое заявление  │
│                                                │
│ H1: <короткий глагол-результат>  ← просто      │
│                                                │
│ SUBHEAD: <слой> связывает <акторов> в <ядро>;  │
│   каждое <решение> — <provable-глагол>;        │
│   <широта: вертикаль · вертикаль · вертикаль>  │
└──────────────────────────────────────────────┘
        ниже по скроллу: lineage-полоса (научный фундамент)
        → возвышенное ядро (named core abstraction) → доказательства
```

## Реализации в твоих проектах

- **RAGRAF** (1-е применение, 2026-06-16) — hero лендинга:
  было «Центр ИИ НГУ · Строительство и городская среда» / «От стройплощадки до
  управления городом» → стало eyebrow «No-code платформа исполняемых
  регламентов · объяснимость по построению» / H1 «**Операционная система
  проверяемых решений**» / subhead со слоем + provability + 13 сфер. Ядро
  («исполняемый граф / Flow DSL») возвышено; lineage = Сибирская матшкола (ИМ СО
  РАН) вместо логотипов. Файлы: `~/RAGRAF/frontend/src/components/landing/LandingScreen.tsx`,
  обоснование — `~/RAGRAF/docs/RESEARCH-POSITIONING-2026-06.md` (§1 лидеры, §4 синтез).
- _(2-е и 3-е применение — заполнить; паттерн «настоящий» с 3-го раза.)_

## Когда **не** применять

- **Продукт реально нишевый / одна вертикаль** — claim «операционная система …»
  прозвучит как overclaim; честнее узкое, но точное обещание.
- **Аудитория покупает результат, не категорию** (SMB, утилитарный B2C) —
  «слой/фундамент» абстрактен, нужен прямой outcome и цена.
- **Нет ни логотипов, ни наследия** — ход №6 не сработает; gravitas брать нечем,
  не надувай.
- **Заявленный provability не подкреплён** — «доказуемых» без структурной
  объяснимости = ложь, которую вскроют на due diligence.

> зафиксирован после первого (RAGRAF) — это кандидат; подтвердить на 2-м и 3-м.

> переносим между продуктами и стеками.
