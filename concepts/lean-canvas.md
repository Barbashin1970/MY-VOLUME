# Lean Canvas

**9-блочный канвас** Эша Маурьи (Ash Maurya, 2010) — адаптация Business
Model Canvas Александра Остервальдера специально для **стартапов** и
**ранних продуктов**.

> Фокус: за **20 минут** уложить идею продукта на одну страницу. Все
> 9 блоков должны быть заполнены — пробелы говорят, что в гипотезе дыра.

## Структура (9 блоков)

```
┌──────────┬─────────┬──────────┬─────────┬──────────┐
│ Проблема │ Решение │ Уникальное │ Преимущество│ Клиентские│
│ (3 топ)  │         │ предложение│ перед     │ сегменты  │
│          │         │ ценности  │ конкурент.│          │
│          ├─────────┤           ├──────────┤          │
│          │ Ключевые │           │ Каналы   │          │
│          │ метрики  │           │ продаж   │          │
├──────────┴─────────┴───────────┴──────────┴──────────┤
│  Структура затрат      │   Источники дохода          │
└────────────────────────┴─────────────────────────────┘
```

| # | Блок | Что внутри |
|---|------|-----------|
| 1 | **Проблема** | 3 топ-проблемы клиента + **существующие альтернативы** (как они решают сейчас — это очень важно) |
| 2 | **Клиентские сегменты** | Кто страдает + **early adopters** (с кого начнём) |
| 3 | **Уникальное ценностное предложение** | Одна фраза, отличающая нас. + «High-level concept» (метафора: «X для Y», «Airbnb для лодок») |
| 4 | **Решение** | 3 ключевые фичи MVP (по одной на каждую проблему сверху) |
| 5 | **Каналы** | Как мы достучимся до клиентов (free + paid + viral) |
| 6 | **Источники дохода** | Цена, бизнес-модель (subscription / one-time / freemium), LTV |
| 7 | **Структура затрат** | CAC, инфра, фикс/var расходы |
| 8 | **Ключевые метрики** | Главные числа для измерения здоровья (AARRR: Acquisition / Activation / Retention / Revenue / Referral) |
| 9 | **Преимущество перед конкурентами** | Что **нельзя скопировать**: процессы, экспертиза, патенты, инсайдер-знание, бренд (это самый сложный блок — часто пустой на ранней стадии) |

## Связь с Product Focus

Lean Canvas — главный артефакт фокуса **«Стратегия»** (пересечение
4 фокусов создания продукта).

- Блоки 1, 2, 9 → фокус **Клиент**
- Блоки 3, 4 → фокус **Продукт**
- Блоки 5, 6, 7, 8 → фокус **Бизнес**
- (Тренды Lean Canvas явно не показывает — это пробел)

## Применение в твоих проектах

### Где Lean Canvas был бы полезен — но не написан

| Проект | Что заполнить |
|--------|---------------|
| **RAGRAF** | Есть [STRATEGY-POSITIONING.md](../projects/active/ragraf/README.md), [ragraf_economics_marketing_report.md] — это **намного больше**, чем Lean Canvas, но **нет компактного экрана-сводки**. Lean Canvas был бы хорош как 1-страничный pitch-deck. |
| **AI-SKLAD** | Есть IDEA.md с 6 вопросами. Можно было бы добавить Lean Canvas — он закрывает «Каналы», «Преимущество», «Структура затрат», которых в IDEA.md нет. |
| **SOFIA** | Готовый продакшен (sofia-europe.vercel.app), но нет канваса. Каналы продвижения, LTV — слабо проработаны. |

### Когда **достаточно** IDEA.md (без Lean Canvas)

- Категория B (pet/learning) — Lean Canvas избыточен.
- Категория C (научно-инструментальный) — Lean Canvas не отражает академическую логику.

### Когда **обязательно** Lean Canvas

- Питч инвестору / партнёру (за 5 минут).
- Грантовая заявка короткого формата.
- Первая встреча с бизнес-заказчиком (b2b).

## Антипаттерны

❌ **Заполнять «как у соседа»** — копируешь чужой канвас → теряешь
   главное, что должно быть **уникальным**.

❌ **Пустой блок «Преимущество перед конкурентами»** — частая ошибка.
   Если действительно пусто, признайся: у нас пока нет несокрушимого
   барьера. Это сигнал к работе.

❌ **«Все клиенты»** в сегментах — значит ни один. Сначала **early
   adopters**.

❌ **Решение раньше Проблемы** — заполняй сверху вниз: Проблема →
   Клиенты → UVP → Решение. Не наоборот.
