# SOFIA — Арома София

> **Где код:** `~/SOFIA/`
> **Прод:** https://sofia-europe.vercel.app/
> **Что это:** персональный ароматерапевтический помощник на основе
> авторской системы «Цветок Мудрости». Категория D — продакшен-демо.

## Зачем

Создание индивидуальных ароматерапевтических смесей на основе **даты
рождения пользователя**. Авторская методика объединяет три слоя:

- **Архетипическая психология (К.Г. Юнг)** — Персона, Тень, Бессознательное, Истинное Я.
- **Нумерология** — расчёт 12 психо-энергетических параметров по дате рождения (редукция к 1–12).
- **Ароматерапия** — подбор эфирных масел с учётом интенсивности и дозировки.

## Главные фичи

- **Цветок Мудрости** — SVG-диаграмма из 12 энергий (Внутренний слой — психика 12 зон по Юнгу) + (Внешний — социум, 4 области).
- **13 рецептов** ароматических смесей.
- **Мягкая консультация** — анкета из 3 вопросов, 5 направлений.
- **Быстрый старт** — профиль + главное масло за один шаг.
- **Несколько профилей** — для себя, друзей, клиентов.

## Стек

| Слой | Технология |
|------|-----------|

## Главные ценности SOFIA для других проектов

1. **Категория D с продом** — единственный твой Vercel-деплой с
   реальным пользовательским потоком (не только демо). Эталон, как
   делать SaaS-light без backend'а.

2. **Доменная модель смешанной природы** — психология + математика +
   biology. Паттерн «формальная таблица соответствий + расчётная
   формула». Переносим: гороскопы, типизации, кадровые тесты, любая
   «персонализация по входному параметру».

3. **SVG-диаграмма как главный артефакт UI** — не canvas/WebGL, не
   D3. Чистый React-SVG. Стоит вытащить в [knowledge/skills/](../../../knowledge/skills/)
   как паттерн «complex visual artifact in plain SVG».

4. **Полная клиентская архитектура** — все расчёты, профили, рецепты
   локально. Не требует backend'а, GDPR-friendly. Паттерн для
   персонализации.

## Что **не похоже** на GONKA/KNIFFEL (важно)

SOFIA ≠ игра. Не переиспользуй из неё game-loop, AI-боты, multiplayer
паттерны. Общее с GONKA: только стек PWA + React + Vite. Доменная и
UX-логика — полностью своя.
