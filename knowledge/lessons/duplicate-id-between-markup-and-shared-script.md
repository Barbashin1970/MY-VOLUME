# Урок: повтор id между разметкой страницы и общим сценарием

## Что произошло

В АРХИ на странице администратора кнопка «Прервать обход» несла
`id="knopka-ostanovit"`. Ровно такой же id присваивает кнопке «Остановить»
общий сценарий шапки `web/obshchee.js`, который подключён ко всем страницам
и рисует полосу состояния.

`prervatObhod()` гасил кнопку на время запроса — и гасил **не свою**:
`getElementById` возвращает первый элемент по порядку DOM, а полоса состояния
стоит в разметке **выше** главной части страницы. Своя кнопка оставалась
нажимаемой, и второе нажатие уходило вторым запросом. Сам запрос при этом
отрабатывал верно, поэтому жалоб не было: защита от двойного нажатия просто
не работала, и заметить это можно было только по коду.

## Почему это случилось

Id в разметке страницы и id, присваиваемые общим сценарием, живут **в разных
файлах и в разных головах**. Автор страницы видит свою разметку и не видит,
что общий скрипт добавит в тот же документ. Автор общего скрипта не знает,
какие id заняты на семи страницах-потребителях.

Браузер при этом не жалуется: дубль id — нарушение спецификации, но не ошибка
исполнения. Валидатор разметки его тоже не поймает — в **файле** дубля нет,
он возникает только при сборке документа в браузере.

## Как починили

Переименовал кнопку страницы в `knopka-prervat` и завёл сторожа, который
сверяет **оба источника сразу**:

```python
iz_razmetki = re.findall(r'\bid="([^"]+)"', razmetka_bez_skripta)
iz_polosy   = re.findall(r'\.id = "([^"]+)"', obshchee_js)
vse = iz_razmetki + iz_polosy
povtory = {i for i in vse if vse.count(i) > 1}
assert not povtory
```

Проверил, что сторож ловит: подсадил повтор обратно — упал с именем.
`ARCHI-NSU/tests/test_stranica_administratora.py`.

## Чтобы не повторилось

- **Есть общий сценарий, создающий элементы с id → сверять надо СОБРАННОЕ,
  а не слагаемые.** Проверка одной только разметки проходит при сломанном итоге.
  То же для пары «файл настроек + умолчания в коде» и для двух лаунчеров.
- Дешёвая профилактика без сторожа: у id, которые ставит общий скрипт, —
  свой префикс (`obshchee-`), и он объявлен в шапке этого скрипта.
- Признак в коде, по которому это ищут: `getElementById` в файле страницы
  на имя, которого в **этой** странице нет глазами, — значит, имя пришло
  откуда-то ещё.
