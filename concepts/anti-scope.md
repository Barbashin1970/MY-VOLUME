# Антископ

**Жёсткий нумерованный список того, чего продукт в первой версии
не делает.** Первоклассный артефакт IDEA.md и любого ТЗ.

> «Жёсткий список того, что в demo и v1.0 **не реализуем** — чтобы
> не расползаться».
> *(`~/AI-SKLAD/IDEA.md` §5)*

## Зачем

| Без антископа | С антископом |
|---------------|--------------|
| Каждый месяц «а давай ещё фичу» | Чёткое «нет», аргументированное |
| Скоуп ползёт, сроки тоже | Сроки держатся |
| Сложно объяснить заказчику «почему не делаем X» | Записано на бумаге |
| Команда добавляет фичи «для красоты» | Команда работает по плану |

## Формат

Нумерованный список 5-15 пунктов. **Каждый пункт — одна строка**.

Пример из AI-SKLAD (10 пунктов):

```markdown
1. **ML-модель.** Rule-based v0.1 в demo. ML (LightGBM / CatBoost /
   Prophet) — после accept, в roadmap.
2. **Интеграция с ERP / WMS / 1С / CRM.** Mock-данные из контролируемого
   генератора. Реальные коннекторы — после accept.
3. **Мобильная версия.** Фаза 5 playbook'а, не раньше.
4. **Multi-tenant / multi-warehouse в одном UI.** Один склад в demo;
   несколько — после accept.
5. **Real-time обновления.** ТЗ требует ежесуточно — этого достаточно.
6. **Редактирование правил классификации в UI.** 7 меток жёстко зашиты;
   расширение — через PR разработчика.
7. **Полноценный RBAC.** Один пользователь-аналитик в demo.
8. **Мультиязычность.** Только русский. Английский — отдельный проект.
9. **Уведомления (email / Telegram).** В demo задачи видны только в журнале.
10. **A/B-тесты вариантов рекомендаций.**
```

**Каждый пункт содержит:**
- **Что не делаем** (жирным).
- Что делаем вместо (один-два слова).
- Когда вернёмся (если вернёмся).

## Где живёт

- В **IDEA.md** §5 — главный список на начало проекта.
- В **ТЗ** — формализованная версия.
- В **ARC.md §16 «Развитие»** — обновлённая после старта.
- В **STRATEGY-POSITIONING §4.2 «От чего отказываемся»** — для рынка
  (другой жанр антископа: не «фичи», а «целевые сегменты/конкуренты»).

## Антипаттерны

❌ **«Не очень понятно, но потом разберёмся».** Точка — антископ
   именно про то, чтобы НЕ разбираться потом.

❌ **«Хорошо бы и это сделать как-нибудь».** Неконкретно → не работает.

❌ **«Хотелось бы поддержать всё».** Если так — нет антископа.

❌ **«Уберём из антископа, как только появится свободное время».**
   Свободного времени не будет. Если убираешь — это новая фаза.

## Антископ-стратегический (для STRATEGY-POSITIONING)

Это не «функции», а **сегменты рынка и конкуренты**:

```markdown
### От чего отказываемся (явно)

- **Не конкурируем с Discovery** в индуктивном выводе.
- **Не конкурируем с Delta** в блокчейне.
- **Не конкурируем с ELMA365 за корпоративный BPM** в массовом сегменте.
- **Не лезем в SCADA/АСУ ТП.** Слой выше.
```

Этот список не менее важен, чем функциональный антископ — экономит
годы попыток выйти не в ту нишу.
