## Стратегия (резюме)

Развилка «монетизировать ИЛИ продать» — **ложная, это последовательность**:

> Построить дешёвую **петлю возврата** (дневник эффектов) + **Ozon-affiliate MVP** →
> собрать **реальные** цифры использования → заменить ими выдуманные проекции в
> питче **Аромашке** (партнёр №1 по рейтингу самого документа: 53/60). Affiliate-доход
> побочный; настоящий апсайд — **сделка с брендом**, а трафик/данные — то, что делает
> сделку реальной, а не «питчем на проекциях».

Keyword-research обслуживает оба конца: ASO/SEO для трафика **и** аргумент «мы владеем
поисковым запросом X» в переговорах.

**Рейтинги интереса брендов (из концепции):**
- РФ: **Аромашка 53/60 (№1)** → Mi&Ko 41 → Botavikos 40 → LeNel 37 → Oleos 34 → Aromatika 29.
- Мир: **Aroma-Zone 38/50 (№1)** → Primavera 35 → Muji 33 → Oshadhi/Tisserand 32 → doTERRA ❌ (MLM, конфликт каналов).
- Affiliate: Ozon 1-15%, WB/Wibes 5%, Amazon 1-10%. MVP проще всего на **Ozon-диплинках**.

## ⚠️ Три возражения (разрешить до масштабирования)

1. **Разрыв «питч ↔ реальность».** Документ написан как для профинансированного
   стартапа с командой (PM, Lead BE + 2 Python, 2 FE, Data Scientist, BizDev, DevOps+QA)
   и запросом **11,5 млн ₽**. Реальность: соло-разработчик, клиентский PWA без бэкенда,
   без команды, без пользователей. Цифры (MAU 120k, ROI >1000%, €16M оборот) —
   проекции из воздуха. → Решить: идти к Аромашке как «соло-автор работающего
   прототипа» (честно) или строить команду под питч.

2. **Монетизация стоит на функциях, которых нет.** Подписка 189 ₽/мес и LTV-история
   держатся на дневнике эффектов + ML-персонализации + «масле дня». В текущем
   приложении этого нет — расчёт «Цветка» одноразовый, удержание слабое. → Строить
   петлю возврата первым делом, она дёшева.

3. **Чья методика «Цветок Мудрости»? — РАЗРЕШЕНО 2026-05-29, КРАСНЫЙ БЛОКЕР.**
   Методика — **Ксении Крокиной**, изданная книга (Эксмо, ISBN 978-5-04-189863-2,
   *«Цветок мудрости. …на основе астропсихологии, нумерологии и ароматерапии»*,
   подзаголовок «как с помощью 12 эфирных масел изменить жизнь»), + онлайн-курс
   AROMA SPACE (aroma.space/course_tsvetok) + её сайт-калькулятор по дате рождения.
   Олег **построил SOFIA сам по её книге/курсу, без договорённости** → ядро = её IP.
   Следствие: **продать/лицензировать SOFIA брендам нельзя** (не владеет IP); публичный
   показ/монетизация — правовой риск. Нюанс: метод как идея не охраняется (ст.1259 п.5
   ГК РФ), но её конкретные таблицы «энергия→масло», названия зон, тексты, диаграммы
   и, возможно, товарный знак «Цветок Мудрости» — охраняются. Нужен реальный юрист.

## Keyword-план (RU, Кластер 1 — tool-intent под новизну «Цветка»)

⚠️ **Поправка по инструментам для RU:** Semrush/Ahrefs по России слабы (Semrush ушёл из
РФ). Порядок: **1) Яндекс Wordstat** (абсолютная частота, бесплатно) → 2) Google Trends
(geo=RU, только тренд/сезонность, не абсолют) → 3) Keys.so / Bukvarix / Mutagen (KD по RU)
→ 4) Semrush/Ahrefs (если есть, с осторожностью).

**Логика softy/noisy** (из [cws-idea-scouting](../cws-idea-scouting/README.md)): приложение
ранжируется как сайт → общие ароматерапевтические запросы шумные (магазины+статьи),
SOFIA там не выигрывает. Выигрывает только узкий tool-intent.

## ВЫБРАННЫЙ ПУТЬ (2026-05-29 вечер): партнёрство с Крокиной

Олег **дружит с Крокиной**, но SOFIA ей ещё не показывал. Разворот: не продавать
брендам (IP не его), а сделать SOFIA **официальным приложением «Цветка Мудрости»** для
её курсов/учеников. Это снимает все три возражения сразу (см. таблицу выше) и даёт канал =
её аудитория. Целевой формат предложения — как ученики получают Софию: бонус/инструмент
курса, режим консультанта (мульти-профиль уже есть), co-branding, affiliate на масла.
Бренды (Аромашка/Aroma-Zone) — позже, через affiliate, не как покупатели.

## Монетизация: честная экономика + регуляторный риск (2026-05-29)

**Affiliate-экономика (оценки, не факты).** Воронка: визит → квиз → клик «купить» →
покупка → комиссия. Доход на 1000 активных/мес: **холодный трафик ~$5** (актив. 40% ·
CTR 10% · конв. 4% · чек $30 · 10%), **тёплый (ученики Ксении) ~$47** (70/20/8% · $35 · 12%).
Amazon — ещё ÷3 (3%, cookie 24ч). Инверсия: $500/мес = ~100K активных (холодный) или
~11K (тёплый); $2000 = 400K / 43K. **Вывод: affiliate в одиночку = «деньги на кофе» без
крупной/тёплой аудитории. Единственный реалистичный $500+/мес — аудитория Ксении.**

**Регуляторный риск (claims).** Ароматерапевтические утверждения «лечит X» = медицинские
claims → отказ в App Store/Google Play, ограничения в EU (особенно DE), предупреждения
FTC/FDA (примеры — doTERRA, Young Living). **Безопасная полоса:** wellness/entertainment,
рамка «по знаку/дате/ритуалу» (явно развлечение, не медицина), дисклеймер + safety-заметки,
язык «для расслабления/настроения», НИКОГДА «лечит/от болезни». «Симптомный» подбор
опаснее «подбора по личности» — ещё аргумент за астро/личностный угол.

**Чем закрыты остальные каналы (итог сессии):** SEO мёртв (Wordstat≈0); extension-инъекция
affiliate запрещена CWS с 10.06.2025; Amazon — webview-бан + cookie 24ч + низкая комиссия;
B2B-продажи Олег делать не хочет. → Работает один сценарий: **PWA + affiliate-кнопки брендов
(не Amazon) + wellness-позиционирование + канал = тёплая аудитория Ксении.**
