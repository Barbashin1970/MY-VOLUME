# Слайды → .txt: как читать выгрузку

## Когда нужно

- Сверить, что сказано в записанном видео (оно идёт по слайдам), с конспектом или сайтом.
- Достать промпты со слайдов дословно.
- До записи проверить, что правки из списка попали в слайды.

Опыт — курс «ИИ в учебном процессе» (PROMPT-Professor), 10.10.2026: три выгрузки
`*.pptx.txt` из Google Slides — лекция 1 (74 слайда), лекция 2 (75), лекция 3 (48).

## Что делает выгрузка

| Особенность | Как выглядит | Чем грозит |
|---|---|---|
| Номер слайда — отдельной строкой | «12» на своей строке. У слайдов с текстом заметок номер стоит дважды: номер, текст (похоже на заметки докладчика), снова номер — лекция 1, слайды 11–26 | считать слайды по строкам-числам нельзя: в лекции 1 их 99 на 74 слайда; заметки легко принять за текст слайда |
| Блоки — не сверху вниз | заголовок после списка; строка роли «Ты — преподаватель…» в конце промпта (лекция 2, слайды 29–30); шаги 1, 2, 5, 3, 4, 6, 7 (лекция 2, слайд 24). Похоже, порядок — по фигурам на слайде, а не по месту | промпт, собранный «как идёт», окажется без роли или с перепутанными шагами |
| Таблица — по ячейке на строку | «Роль / Что делает / Стиль / Документы / Лектор-визионер / …» | таблицу восстанавливать по числу столбцов шапки |
| Начало, выделенное жирным, склеено с текстом | «ROLEТы — методист…», «Понимание голоса, языка и текстовЧат-боты…» | поиск по фразе не находит; границу ставить вручную |
| Мягкий перенос (Shift+Enter) — символ U+000B | «Спасибо ␋за участие»; в трёх файлах — 36, 17 и 18 штук | `splitlines()` режет по нему: 789 строк против 754 у `split("\n")` — см. урок о `splitlines()` |
| Невидимые символы | U+200B в концах строк (71 и 41 в двух файлах), U+FEFF внутри фраз (4) | точный поиск и сравнение строк промахиваются |
| Слайд-картинка или скриншот | от слайда остаётся только номер (лекция 1 — слайды 8, 10, 54, 55; в лекции 2 — больше десятка) | содержимое кадра проверять по видео или PDF |
| Номера между редакциями | в списке правок к версии 0.5 номера на 3–6 больше, чем в версии 2026 года | сопоставлять слайды по смыслу, не по номеру |

## Как читать

```python
import re
t = open(put, encoding="utf-8").read()
t = t.replace("﻿", "").replace("​", "")   # невидимые символы
t = t.replace("\x0b", "\n")                          # мягкий перенос → строка
stroki = t.split("\n")                               # не splitlines()
nomer = [i for i, s in enumerate(stroki) if re.fullmatch(r"\d{1,3}", s.strip())]
# граница слайда — строка из одного числа; два одинаковых номера подряд
# с текстом между ними — это заметки к слайду, а не его текст
```

Промпт со слайда собирать по смыслу: роль — в начало, шаги — по номерам; где сомнение —
кадр из видео. Строку «Промпт:» или подпись под промптом не путать с его текстом.

## Проверять правки до записи

Каждая правка «убрать» из списка правок — фраза, которой в слайдах быть не должно.
Её ищут в свежей выгрузке **до записи**:

```bash
# stop-frazy.txt — по фразе в строке; выгрузку сначала нормализовать (см. выше)
grep -n -F -f stop-frazy.txt normalizovannaya-vygruzka.txt
```

В курсе 2026 года этого не сделали. В видео лекции 1 не попали четыре правки «убрать»
из десяти, ещё две — частично: «97 % success rate», ошибки в образце теста по Киевской
Руси, «вайб-кодинг не подходит для образования». Видео уже не переснять, поэтому на сайт
пришлось добавить к каждой лекции блок «Что уточнено после записи видео».
