# Урок: «норма» при неполных данных — вывод, а не дефект

## Что произошло

Смежная методология (мэрия, 31.10.2026) формулирует инвариант: «непроверенная
обязательная часть блокирует окончательный положительный результат». Измерение по корпусу
РАГРАФ показало: у 6 из 8 регламентов с выходом «норма» и двумя и более входами «норма»
срабатывает при неизвестном входе. Первая формулировка в разборе — «двойственное свойство
не выполняется, честный пробел изделия».

## Почему это случилось

Смешались два вопроса. Первый — устойчив ли вердикт одного правила при неполных данных.
По теореме о сохранении вердикта внутри фрагмента L₀ — устойчив: «перехода через ноль нет,
если днём не теплеет до +1 °C» верно при любом ночном минимуме, потому что в сильной логике
Клини `ложь ∧ неизвестно = ложь`. Такая «норма» — законный вывод из известного, а не
догадка. Второй вопрос — считать ли **дело** соответствующим, пока часть обязательных
проверок не завершена. Это конъюнкция определённых положительных исходов всех правил —
свойство агрегата, объекта «дело», которого у изделия нет. Инвариант методологии относится
ко второму вопросу, а измерение отвечало на первый.

## Как починили

- Утверждение переформулировано: внутри фрагмента положительный вердикт регламента
  устойчив; полнота положительного результата определяется для агрегата по делу,
  и его в изделии нет — это и есть пробел.
- Единственный настоящий случай отменяемой «нормы» — регламент вне фрагмента
  с подстановкой значения по умолчанию (`x if x != None else 1`): он назван отдельно.
- Решение о предикате «все проверки определённы» отложено владельцем в бэклог
  с признаком возврата.

## Чтобы не повторилось

- Прежде чем назвать поведение дефектом, спросить, не следствие ли оно доказанного
  свойства; если да — дефект лежит в другом месте (в отсутствующем объекте,
  в требовании не того уровня).
- Разделять уровни: семантика одного правила и требования к агрегату — разные объекты,
  и инвариант, сформулированный для агрегата, нельзя проверять на правиле.
- «Нарушений не найдено» и «соответствие подтверждено» — разные вердикты: первый
  вычисляется правилом, второй требует перечня обязательных проверок и факта их завершения.
