# Сигма-методология

Методология построения программ с **гарантированно полиномиальной
сложностью** и предсказуемым завершением. Разработана сибирскими
математиками: С.С. Гончаров, Н.А. Нечесов, Д.И. Свириденко (Институт
математики им. Соболева СО РАН, НГУ).

Применяется в проектах [POLINOM](../projects/active/) и
[POLINOM-JAVA](../projects/active/).

## 32 анти-паттерна (sigma-audit)

POLINOM реализует CLI-аудитор `sigma-audit`, который сканирует Python-код
на **32 канонических анти-паттернов**:

- **M1-M4** — мутации / монотонность
- **T** — типы и аннотации
- **P5-P9** — расширенные питон-правила
- **J1-J5** — Jupyter / интерактивная среда
- **S1-S6** — структура (DRY, KISS)
- **R1-R2** — рекурсия
- **X1** — экстремальные случаи

Из них **12 чинятся автоматически** с доказательством эквивалентности
(`verify`), 10 — detect-only с объяснением.

## Применение

| Когда применять | Когда нет |
|-----------------|-----------|
| Production-сервисы с SLA | Прототип / спайк |
| Код, который попадает в гос/корп инфра | Скрипт-однодневка |
| ML-pipeline с критическими данными | Учебный проект |
| Финтех, медицина, госуслуги | Pet-проект |

## Связь с задачным подходом

Сигма-методология **и** задачный подход — две ветки **одной Сибирской
школы**. Сигма — про **гарантии исполнения** (сложность, завершение).
Задачный подход — про **полноту описания задачи** (4 компонента).
Не конкурируют, а дополняют.

См. `~/RAGRAF/docs/STRATEGY-POSITIONING.md` §1 — это «академический ров»,
который не предъявят коммерческие конкуренты (ELMA, Naumen).

## Промежуточные продукты

- `sigma-audit` CLI — статический анализатор без LLM.
- `agent-rules` — drop-in инструкции для AI-агентов (Claude, Cursor,
  Copilot, Aider, Continue.dev). Превращают любого агента в
  Sigma-aware за один скопированный файл.
- Эмпирический бенч на Python + Java (JMH) — 13 контролируемых
  примеров для валидации, какие правила переносятся в каждую среду без
  потерь.

## Не путать с

- [zadachny-podhod](zadachny-podhod.md) — родственная теория, другой

  линтеры — на эмпирические эвристики.
