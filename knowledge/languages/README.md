# knowledge/languages/

Заметки про **языки** — то, что специфично языку, не привязано к фреймворку.

## Принцип организации

Один файл = одна тема внутри одного языка. Имя файла начинается с языка:

```
python-async-context.md
python-typing-protocols.md
typescript-strict-mode-gotchas.md
java-records-vs-classes.md
```

## Когда сюда писать

- Поведение языка, которое тебя один раз удивило (TS narrowing, Python GIL).
- Идиома, которая стала твоей: «я всегда пишу X вот так».
- Тонкость стандартной библиотеки, на которую ушло > 30 минут разбираться.

## Когда **не** сюда

- Это про фреймворк (FastAPI, React) → `../stacks/`.
- Это про инструмент (uv, pnpm, tsc) → `../tools/`.
- Это рецепт «как сделать X» → `../skills/`.
