# Юнит-экономика

**«Сколько мы зарабатываем на одном клиенте (юните) после вычета затрат
на его привлечение и обслуживание».** Если число положительное —
экономика **сходится**. Если отрицательное — каждый клиент приносит
убыток, продукт не масштабируется.

## Размер рынка: TAM / SAM / SOM

| Метрика | Что это | Пример (ароматерапия в РФ) |
|---------|--------|----------------------------|
| **TAM** — Total Addressable Market | Весь возможный рынок при идеальных условиях | Все взрослые в мире, интересующиеся самопознанием — ~500 млн × $10/год = $5 млрд |
| **SAM** — Serviceable Available Market | Часть TAM, которую реально можем обслужить (язык, география, регуляторика) | Русскоязычные пользователи + платёжная инфраструктура — ~5 млн × $10 = $50 млн |
| **SOM** — Serviceable Obtainable Market | Реалистичная доля SAM, которую возьмём за N лет (с учётом конкурентов) | 1% от SAM за 3 года = $500K/год |

> **Правило больших пальцев:** TAM в питч-деке должен быть «вкусным»
> (миллиарды), SOM — реалистичным (миллионы). Если SOM < $1M — рынок
> слишком мал для венчурных инвестиций (но может быть отличной нишей
> для lifestyle-business).

## Метрики одного клиента

| Метрика | Формула | Что показывает |
|---------|---------|----------------|
| **ARPU** — Average Revenue Per User | выручка / **все** пользователи (включая бесплатных) | Средний доход на одного пользователя |
| **ARPPU** — Average Revenue Per **Paying** User | выручка / только **платящие** | Средний чек платящего |
| **CAC** — Customer Acquisition Cost | расходы на маркетинг / новые клиенты | Стоимость привлечения одного |
| **LTV** — Lifetime Value | ARPU × средний срок жизни клиента (months) | Сколько заработаем за всю «жизнь» клиента |
| **Контрибуция** | LTV − CAC | Сколько чистого заработаем на одном клиенте |
| **Payback period** | CAC / (ARPU × маржа) | За сколько месяцев окупится привлечение |

## Главное правило сходимости

> **LTV / CAC ≥ 3** — экономика здоровая
> **LTV / CAC ≥ 1, но < 3** — выживание, нет ресурсов на рост
> **LTV / CAC < 1** — каждый новый клиент убыточен, скейл усугубит проблему

## Когда юнит-экономика **не** работает напрямую

- **Двухсторонние маркетплейсы** — нужно считать обе стороны (water + boat).
- **Бесплатные внутренние инструменты** (LEYKA) — LTV нет, считаем экономию рабочего времени.
- **Научные инструменты** (POLINOM) — нет CAC, нет LTV, только цитируемость и грантовая отдача.
- **Государственные заказы** — выручка известна заранее, CAC = стоимость подготовки конкурсной документации.

## Применение в твоих проектах

| Проект | Что считать |
|--------|------------|
| **SOFIA** | TAM (русскоязычные ищущие смысл) → SAM (готовые платить за ароматерапию) → SOM (реалистично в первый год). ARPU = 0 пока бесплатно, нужна модель монетизации. |
| **RAGRAF** | B2B, считается **deal economics**: стоимость продажи (включая ТЭО) vs средний чек контракта × марже × вероятности удержания |
| **AI-SKLAD** | Если коммерческий — CAC через рассылку клиентам vs ARPPU подписки |
| **LEYKA** | Внутренний — считай **экономию часов** руководителей × ставка × количество = ROI |

## Антипаттерны

❌ **Брать LTV из чужого исследования** — он всегда специфичен для модели и канала.

❌ **Считать LTV до того как накопилось 6+ месяцев данных** — оценка будет фантомной.

❌ **Игнорировать когортный анализ** — средний LTV скрывает, что 90% уходит через неделю, а 10% живут 5 лет.

❌ **CAC только по платным каналам** — органика тоже стоит времени и контента.
