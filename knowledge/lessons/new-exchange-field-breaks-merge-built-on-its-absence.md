# Урок: «формат начал нести поле, а слияние об этом не узнало»

> Контекст: РАГРАФ, 15.10.2026. Единица измерения параметра жила в таблице
> кода. Её перенесли в данные регламента: выгрузка пишет `:x :unit "мм"`,
> разбор читает, таблица кода осталась запасным путём.

## Что произошло

Проверки «записал → прочитал» прошли: единица переживает выгрузку и разбор.
Но есть третий путь — сохранение из Turtle-редактора. После разбора
обработчик восстанавливает из базы поля, которых Turtle не несёт, и единица
стояла в их списке:

```python
# existing.unit ВСЕГДА побеждает (Turtle не несёт unit как триплет)
if ep.unit is not None:
    p.unit = ep.unit
```

Пользователь видит в редакторе `:unit "мм"`, меняет на «см», сохраняет —
и получает «мм». Ни ошибки, ни предупреждения.

## Почему это случилось

- **Правило слияния было верным, пока поля не было в формате.** Его довод
  записан как факт о формате — в комментарии кода и в описании языка
  («что Turtle не переносит: единица…»). Поле добавили — факт изменился,
  правило осталось.
- **Разбор не говорил, откуда значение.** Разборщик заполнял единицу и из
  текста, и из таблицы кода. По разобранному объекту нельзя отличить правку
  пользователя от умолчания, и слияние вынуждено выбирать вслепую.
- **Проверяли пару «запись — чтение», а не путь целиком.** Путь
  «прочитал → слил с хранилищем → записал» отдельной проверки не имел.

## Как нашли

Не проверками. При обновлении описания языка строка «Turtle не переносит
единицу» стала ложной. Поиск того, что опирается на это «не переносит»,
привёл к обработчику сохранения.

## Как починили

- функция `obyavlennye_edinicy(text)` возвращает только единицы, **объявленные
  в тексте**;
- слияние — по происхождению значения: объявленная единица — правка
  пользователя и побеждает; необъявленная берётся из базы, потому что
  нестандартную единицу («км/ч», «гПа») таблица кода не знает;
- проверка через приложение: правка «мм → см» принимается, а нестандартная
  «км/ч» без объявления сохраняется; видели красной.

Коммит `fa61b77` в РАГРАФ (`api/regulations.py`, `services/turtle_bridge.py`).

## Чтобы не повторилось

- **Добавил поле в формат обмена — найди всё, что опиралось на его
  отсутствие:** правила слияния «хранилище побеждает», комментарии «формат
  не несёт X», раздел документа «что не переносится». Этот раздел и есть
  готовый список мест для проверки.
- **Разбор с умолчаниями обязан уметь сказать, откуда значение** — из текста
  или по умолчанию. Иначе любое слияние вынуждено гадать.
- **Правило слияния формулируй по происхождению, а не по полю:** объявленное
  во входящем побеждает, необъявленное берётся из хранилища.
- **Испытывай путь целиком через точку входа.** Пара «записал → прочитал»
  не покрывает «прочитал → слил → записал».
