# Урок: «0,01 м снега, напечатанные как 0,01 см»

> Контекст: РАГРАФ, регламент перехода температуры через ноль
> (`campus-zero-crossing`): наледь, сосульки, обработка дорожек. Высота снега
> приходит от Open-Meteo. С 15.10.2026 сообщение о вердикте несёт «основание» —
> величины с единицами (`backend/app/services/osnovanie.py`).

## Что произошло

В рабочем чате основание вердикта гласило: «Высота снега, м = 0,01 см».
Число верное, подпись врёт в сто раз — и в одной строке противоречит сама себе.

## Почему это случилось

- Open-Meteo отдаёт `snow_depth` **в метрах**; порог в формуле регламента —
  `snowDepth >= 0.01`, то есть сантиметр снега.
- Единицу параметра разборщик Turtle брал из таблицы в коде `PARAM_UNITS`
  (`backend/app/services/turtle_bridge.py:52`), где `"snowDepth": "см"`. Таблицу
  писали под другой регламент — сугробы на кровле, где снег меряют сантиметрами.
- **Справочник ключуется по имени величины, а имя одно на два смысла.**
  Код не может знать, из какого источника пришло значение, поэтому любая
  единица в такой таблице кому-то врёт.

## Как починили

1. С 15.10.2026 (`fa61b77`) единица — часть описания регламента: предикат `:unit`
   у свойства в Turtle; объявленная единица главнее кодовой таблицы, таблица
   осталась запасным путём.
2. В поставке регламента объявлено `:snowDepth … :unit "м"`.
3. На действующем экземпляре единицу в таблице `parameters` поправила разовая
   миграция `edinica_vysoty_snega_v1` (27.10.2026, `5188893`).
4. Проверки: `test_vysota_snega_v_metrah_kak_v_istochnike`,
   `test_migraciya_edinicy_vysoty_snega_na_tome`. Разбор —
   `docs/OBRATNAYA-SVYAZ-RAZBOR.md`, § 9, работа С4.

## Чем обнаружено

Чтением живого сообщения на проде при разборе обратной связи 27.10.2026.
Проверки были зелёными: они сверяли число, а не подпись к нему.

## Чтобы не повторилось

- **Единица берётся из того же места, что и значение:** из описания источника
  или регламента, а не из глобального справочника по имени.
- **Глобальная таблица «имя → единица» — запах.** Как только одно имя приходит
  из двух источников, она начинает врать. Допустима только как запасной путь,
  с пометкой «объявлено» / «по умолчанию».
- **Сверяя пороги, сверяй и единицы.** Порог 0,01 осмыслен только вместе с «м».
- **В словаре данных у каждого числового поля — единица и источник единицы.**
- **Проверка печати:** основание в сообщении сверяют целиком, вместе с единицей,
  на значении из реального ответа источника.
