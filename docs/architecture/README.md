# docs/architecture/

Здесь — **готовые архитектурные документы**, по одному на систему.

## Чем отличается от `projects/<x>/arc.md`

| `projects/<x>/arc.md` | `docs/architecture/<x>.md` |
|-----------------------|---------------------------|
| Одна страница для тебя | Полный обзор для коллег |
| Кратко, как памятка | Развёрнуто, с обоснованиями |
| Меняется быстро | Снапшот, обновляется реже |
| Без диаграмм или ASCII | С нормальными SVG/Mermaid |

## Что писать

- Контекст (кто пользователи, какие нагрузки).
- Высокоуровневая диаграмма компонентов.
- Описание каждого компонента — 1-2 абзаца.
- Data flow для главных сценариев.
- Trade-off'ы: что выбрали и почему (со ссылками на [decisions/](../decisions/)).
- Границы системы: что **не** делает.
