# Урок: угаданный адрес `*.vercel.app` — не обязательно твой

## Что произошло

26.10.2026, опись проектов для сайта-портфолио (`~/portfolio/docs/INVENTORY.md`).
У части проектов адреса демо не были записаны, и их достраивали по имени:
проект `boardway` → `boardway.vercel.app`.

Адрес ответил **200**. Под ним оказалась **чужая англоязычная игра-монополия**.
Настоящий Boardway — бизнес-симулятор на русском — живёт на `boardway-nsk.vercel.app`:
этот адрес дал владелец, и он подтвердился текстом игры в бандле.

Рядом в той же описи — тот же жанр с другим исходом: адрес `tigra.vercel.app`
из README проекта отвечает **402**, рабочий — `tigra-dice.vercel.app`.

## Почему это случилось

Поддомены `*.vercel.app` — одно пространство имён на всех пользователей. Короткое
имя достаётся тому, кто занял его первым; остальные получают адрес с добавкой.
В той же описи таких адресов несколько: `gonka-two`, `sigma-three-theta`,
`workout-eight-flax`, `15-puzzle-mu`.

Код ответа говорит только «по адресу что-то есть». Чьё оно — не говорит.

## Как починили

- Чужой адрес отброшен и записан в опись как отброшенный, с причиной.
- Каждый адрес на витрине сверен по содержимому: `<title>`, а у одностраничных
  приложений — что отдаётся сам бандл и в нём есть текст своего проекта.

```bash
curl -sS -L --max-time 40 -o page.html -w "%{http_code} %{url_effective}\n" "$URL"
grep -o -i '<title[^>]*>[^<]*' page.html | head -1
src=$(grep -oE '<script[^>]*src="[^"]+"' page.html | grep -oE 'src="[^"]+"' | head -1)
```

27.10.2026 так же проверены три игры, найденные в старом репозитории: все отвечали
200, и только `<title>` («Пятнашки», «Boston Consulter», «Profconsalt») и Expo-бандл
подтвердили, что это они.

## Чтобы не повторилось

- **Адрес демо берётся из источника** — README проекта, настроек деплоя, слов
  владельца, — а не достраивается по имени репозитория.
- **Ссылка проверяется содержимым, а не кодом ответа.** Минимум — `<title>`;
  для SPA — бандл и строка своего текста в нём.
- **Адрес из README тоже проверять:** он устаревает (402 у `tigra.vercel.app`).
- **Отброшенный адрес записывать в опись** с причиной — иначе следующий проход
  угадает его снова.
