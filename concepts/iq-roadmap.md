# IQ-roadmap — модель роста системы

**Уникальный паттерн** Олега: моделировать развитие продукта как
последовательное **прохождение фаз с числовой метрикой суммарного
«интеллекта»**. Эталон — `~/NSK_OpenData_Bot/IQ-roadmap.md`.

## Идея

Большинство roadmap'ов — это «список фич». IQ-roadmap — это **трек
прокачки**: текущий уровень → следующий уровень с понятной метрикой
сколько баллов прибавится.

Из NSK:
> «Текущий охват: ~35-40 баллов из 120 (хорошо покрыты ЖКХ, экология,
> транспорт). Цель к ПМЭФ: ~60-70 баллов — среднероссийский уровень».

## Структура IQ-roadmap

### 1. Метрика и её источник

Лучше всего — **внешняя стандартизованная метрика**. Для NSK это
«IQ-индекс городов» от Минстроя РФ (14 направлений, max 120 баллов).

Альтернативы:
- Doneness checklist по гайдлайнам (ISO, ГОСТ, OWASP top-10)
- Покрытие конкурента (% фич, что уже умеем)
- Покрытие пользовательских сценариев (JTBD)

### 2. Карта направлений (измерений)

Таблица: направление / текущий статус / приоритет.

| # | Направление | Текущий статус | Приоритет |
|---|-------------|----------------|-----------|
| 1 | … | ✅ Реализовано | — |
| 2 | … | ⚠ Частично | Фаза 2 |
| 3 | … | ❌ Нет | Фаза 4 |

### 3. Фазы — последовательные этапы

```markdown
## Фаза 1 — «<Название>» (текущая)
**Статус: в работе** | **Ожидаемый прирост IQ: +5 баллов**

| Задача | Источник | Сложность | Файлы |
| … | … | … | … |
```

### 4. Оценка прироста

| Фаза | +баллов | Итого |
|------|---------|-------|
| Базовый | ~35 | 35 |
| Фаза 1 | +5 | 40 |
| Фаза 2 | +10 | 50 |
| … | … | … |

### 5. Технический шаблон расширения

Quick reference из 5-7 шагов «как добавить новую единицу»:

```
1. Данные: добавить в config/datasets.yaml ИЛИ src/<topic>_data.py
2. Роутер: _route_<topic>() + регистрация
3. Планировщик: ветка в make_plan()
4. Исполнитель: execute_<topic>()
5. API: ветка if topic == "<topic>":
6. Рендер: renderTopic() + dispatch
```

## Когда применять

| ✅ Подходит | ❌ Не подходит |
|------------|----------------|
| Продукт = агрегатор/индекс (NSK) | Линейный feature-line продукт |
| Есть внешняя стандартизованная метрика | Метрика только внутренняя и спорная |
| Долгий горизонт (1-3 года) | Спринт на 2 недели |
| Гос/корп заказчик с KPI-отчётностью | Pet-проект |

## Преимущества

1. **Видна позиция** на шкале (3-х из 14 фаз — visible progress).
2. **Внешний обоснователь** — есть на что сослаться в гранте.
3. **Дискретные milestone-цели**: «к ПМЭФ → 60 баллов» — конкретно.
4. **Авто-планирование** — фазы упорядочены по приоритету.

## Антипаттерны

❌ **Метрика без источника** — придуманная шкала не убеждает.
❌ **Слишком много направлений** (> 15) — теряется фокус.
❌ **Фазы без прироста баллов** — нечего показать заказчику.
❌ **Метрика, которую невозможно проверить** — не работает.

## Где встречается

- `~/NSK_OpenData_Bot/IQ-roadmap.md` — главный эталон (IQ городов).
- В коммерческих проектах эквивалент — TRL (Technology Readiness Level
