# ГОСТ-19 / ЕСПД

**Единая система программной документации** — российский стандарт
оформления документации на ПО. Серия `ГОСТ 19.xxx-YY`, действует с
1978-1980 годов с переизданиями.

## Главные стандарты серии

| ГОСТ | Документ | Применение |
|------|----------|------------|
| **19.001-77** | Общие положения | Метастандарт |
| **19.101-77** | Виды программ и программных документов | Что вообще существует |
| **19.102-77** | Стадии разработки | НИР → эскизный → технический → рабочий → испытания → внедрение |
| **19.201-78** | **Техническое задание** | ТЗ — самый частый документ |
| **19.301-79** | **Программа и методика испытаний (ПМИ)** | Формальная приёмка |
| **19.401-78** | Текст программы | Не используем — слишком формально |
| **19.402-78** | Описание программы | Не используем |
| **19.502-78** | **Инструкция по установке** | При поставке |
| **19.503-79** | **Руководство системного программиста (админа)** | Multi-user |
| **19.504-79** | Руководство программиста | Не используем для legacy |
| **19.505-79** | **Руководство оператора (пользователя)** | Перед релизом |

## Что Олег реально использует

См. `~/RAGRAF/docs/SKILL-GOST-19.md` — мета-документ конвенций. Из 11
стандартов выше **используются 5**: 19.201, 19.301, 19.502, 19.503,
19.505. Плюс класс **АРХ** (архитектура) — не из ГОСТ, а внутренний.

| Класс | Расшифровка | Документ-эталон в LEYKA |
|-------|-------------|------------------------|
| `ТЗ` | Техническое задание | `LEYKA_TZ_GOST19.md` |
| `АРХ` | Описание архитектуры (внутренний) | `ARC.md` |
| `РО` | Руководство оператора | `LEYKA_UserManual_GOST19.md` |
| `РС` | Руководство админа | `LEYKA_AdminGuide_GOST19.md` |
| `ИУ` | Инструкция по установке | `LEYKA_InstallManual_GOST19.md` |
| `ПМИ` | Программа и методика испытаний | `LEYKA_PMI_GOST19.md` |

## Обозначение документа

Формула: `<СОКР_ПРОЕКТА>.<КЛАСС>.NNN-YYYY`.

Примеры:
- `LEYKA.ТЗ.001-2026`
- `РГРФ-02-01-01-1/1-ТЗ` (альтернативная форма)
- `РАГРАФ.РО.001-2026`

## Когда обязателен

| Контекст | ГОСТ-19 обязателен? |
|----------|---------------------|
| Open-source pet | ❌ нет |
| Внутренний инструмент команды | ❌ нет |
| Заказчик — НГУ / госструктура / Минобрнауки | ✅ да |
| Грантовая отчётность | ✅ часто да |
| Реестр российского ПО (Минцифры) | ✅ нужен полный комплект |
| Закрытая поставка по 44-ФЗ / 223-ФЗ | ✅ да |

## Что НЕ ГОСТ-19, но похоже

- **ГОСТ Р 59276-2020** — «Системы искусственного интеллекта.
  Объяснимость». Применим к ML-/AI-системам, проверяется отдельно.
- **ГОСТ Р 56939-2016** — «Защита информации. Разработка безопасного
  ПО». DevSecOps.
- **ГОСТ 34** — Информационная технология. Сложнее и шире, для крупных АИС.
