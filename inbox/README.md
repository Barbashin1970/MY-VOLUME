# inbox/

«Чердак» vault'а. Сюда падают **необработанные мысли**, когда некогда
думать, в какую папку положить.

> Правило: **раз в неделю** `inbox/` разбирается. Каждый файл либо
> переезжает в осмысленное место, либо удаляется. **Inbox не растёт.**

---

## Когда писать сюда

- На совещании пришла мысль — записал, чтобы не забыть.
- Прочитал статью — выписал три тезиса.
- Поймал баг — отметил, разберусь вечером.

Любой быстрый сброс. Лучше в inbox, чем не записать вообще.

## Имя файла

`YYYY-MM-DD-короткая-тема.md`. Дата — обязательна (видно «старьё», которое
давно пора разобрать).

## Что делать раз в неделю

Открой `inbox/` → по каждому файлу решение:

| Содержание | Куда переезжает |
|------------|----------------|
| Идея для проекта | `projects/<x>/backlog.md` |
| Полезный приём | `knowledge/skills/` или `knowledge/patterns/` |
| Урок / баг | `knowledge/lessons/` |
| Новый термин | `concepts/` |
| Архитектурное решение | `docs/decisions/` (если созрело) или `projects/<x>/decisions.md` |
| Воды нет, бесполезно | **Удалить.** Не жалей. |

## Что **не** делать с inbox

- Не накапливать дольше недели.
- Не оформлять «красиво» при создании — иначе перестанешь сбрасывать.
- Не давать на чтение коллегам — это твой черновик.
