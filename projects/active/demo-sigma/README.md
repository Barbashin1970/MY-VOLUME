# demo-sigma-main — Sigma Demo

> **Где код:** `~/demo-sigma-main/`
> **Прод:** https://sigma-operator.vercel.app/operator/hospital-fire
> **Что это:** демонстрационный фронтенд **Σ Сигма** — ИИ-прослойки над
> ситуационным центром / ЕДДС. Категория C — научно-инструментальный
> демо-стенд для индустриального партнёра.

## Зачем

Показать три параллельных нарратива работы оператора ситуационного
центра:

- **Кампус НГУ** — пожар в серверной, прорыв теплового ввода в клинике, лесной дым, протечка в общежитии, проникновение в лабораторию, забытый пропуск, проход по поручителям.
- **Муниципальная ЕДДС р.п. Кольцово** (индустриальный партнёр) — переход службы из повседневной деятельности в повышенную готовность по совокупности низкоуровневых триггеров.

## Архитектура

**SPA, полностью клиентский.** Демо детерминированное (без fetch/axios).

## 5 режимов работы (URL-маршруты)

| URL | Кому |
|-----|------|
| `/operator/:scenarioId` | Рабочая станция оператора. Транспорт (Шаг/Сброс), AI-подсказки Sigma Assist, каталог сценариев. |
| `/display/:scenarioId` | Видеостена. Read-only, управление — через BroadcastChannel из оператор-вкладки. |
| `/trainer/:scenarioId` | Тренажёр. Оператор выбирает действие из `allowedActions`, получает балл, анкета + аттестационный отчёт JSON. |
| `/regulations` | Просмотрщик регламентов: витрина `situation` / `actions` + «Чего не делать» по 5 RiskKind. YAML/JSON экспорт. |
| `/` | Редирект на `/operator/hospital-fire`. |

## Главные ценности demo-sigma для других проектов

1. **Паттерн «оператор + видеостена + тренажёр»** — три role-specific UI
   на одних данных. Видеостена через BroadcastChannel — без сервера.

2. **Детерминированное демо без fetch** — все сценарии в коде/YAML,
   нет зависимостей от backend'а. Эталон, как делать **демо для
   показа** партнёру: работает локально, на стенде, на ноутбуке без
   интернета.

3. **«Чего не делать» по 5 RiskKind** — паттерн анти-инструкции рядом
   с инструкцией. Применимо во всех regulation-проектах
   (RAGRAF / STROY / NSK).

4. **Транспорт (Шаг/Сброс)** — пошаговое проигрывание сценария как у
   презентации. Хороший UX для демо.

5. **Аттестационный отчёт JSON** — формализованный артефакт тренажёра.
   Переносим в любую систему оценки персонала.
