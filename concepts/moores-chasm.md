# Пропасть Мура

**Технологический продукт умирает не от плохой идеи, а от пропасти
между ранним рынком и массовым.** Концепция Джеффри Мура (1991) на
базе диффузионной модели Эверетта Роджерса (1962).

## Кривая принятия инноваций

```
         Раннее                                        Поздние
        большинство                                  отстающие
            ▲                                            ▲
            │ ┌────┐                                     │
     ┌──────│ │    │ ┌────┐                              │
     │ ┌────┘ │    │ │    │ ┌────┐                       │
     │ │     │    │ │    │ │    │ ┌────┐ ┌────┐ ┌────┐  │
     │ │     │    │ │    │ │    │ │    │ │    │ │    │  │
     │ │     │    │ │    │ │    │ │    │ │    │ │    │  │
─────┴─┴─────┴────┴─┴────┴─┴────┴─┴────┴─┴────┴─┴────┴──
   2,5%   13,5%    34%             34%       16%
 Innovators │ Early │            Late          Laggards
            │Adopters│            Majority
            │       │
            │       ▼
            │  ⚠️ ПРОПАСТЬ ⚠️
            │
            ▼
    Early Majority
```

## 5 групп пользователей

| Группа | Доля | Кто они | Что им важно |
|--------|-----|---------|--------------|
| **Innovators** (новаторы) | 2,5% | Технологи, изобретатели, гики | Сам факт инновации, новизна |
| **Early Adopters** (ранние последователи) | 13,5% | Визионеры, ранние коммерсанты | Конкурентное преимущество, готовы рисковать |
| **Early Majority** (раннее большинство) | 34% | Прагматики | **Референсы от похожих компаний**, проверенность |
| **Late Majority** (позднее большинство) | 34% | Консерваторы | Стандарт индустрии, низкая цена, поддержка |
| **Laggards** (отстающие) | 16% | Скептики | Прижмёт — купят, не прижмёт — не купят |

## Где «пропасть»

Между **Early Adopters** и **Early Majority**. Их мотивы **противоположны**:

| Early Adopters | Early Majority |
|----------------|----------------|
| «Я хочу быть первым» | «Я хочу быть как все успешные» |
| Готов терпеть сырость | Хочет полный готовый продукт |
| Покупает обещание | Покупает результат |
| Доверяет визионеру | Доверяет референсам |

**Стратегии стартапов рассчитаны на левую группу.** Тактика, которая
сработала на Early Adopters (личные продажи, обещание, страсть), не
работает на Early Majority.

## Как переходить пропасть (Мур)

1. **Выбрать одну нишу-плацдарм** (beachhead market). Один сегмент,
   одна конкретная боль. Без распыления.
2. **Сделать «whole product»** — не MVP, а полноценное решение для
   этой ниши (включая обучение, поддержку, документацию).
3. **Получить 2-3 публичных референса** в нише — это валюта прагматиков.
4. **Расширяться в соседние ниши** через эти референсы (bowling alley
   strategy).
5. Только после этого — массовый рынок (tornado).

## Применение в твоих проектах

| Проект | Где сейчас на кривой | Что мешает перейти пропасть |
|--------|---------------------|----------------------------|
| **RAGRAF** | Innovators / Early Adopters (НГУ, отдельные заказчики) | Нужны 2-3 публичных кейса с метриками экономии. Без них прагматики не купят. |
| **LEYKA** | Innovators (внутренний) | Нужен whole product: онбординг, документация для конечных пользователей, миграция данных. |
| **SOFIA** | Innovators (Олег + ближний круг) | Прагматики не верят в нумерологию. Лучше **остаться** в Early Adopters (визионеры от self-development), не пытаться в массмаркет. |
| **AI-SKLAD** | Pre-innovators (только демо) | Нужно сначала на Innovators (один заказчик-новатор) с реальными данными. |
| **POLINOM** | Innovators (научное сообщество) | Академический рынок имеет **свою** кривую (цитирования + гранты), не классический B2B. |

## Связь с другими моделями

- **AARRR** работает по-разному на разных группах: Innovators активируются от технологии, Early Majority — от витрины кейсов.
- **Bartle**: Innovators = Explorers, Early Adopters = Achievers, Early Majority = Socializers (доверяют референсам), Laggards = Killers (придут только под давлением).
- **Lean Canvas**: блок «Early adopters» — это **именно** Innovators + Early Adopters Мура.

## Антипаттерны

❌ **«Наш продукт для всех»** — на ранней стадии это значит ни для кого.

❌ **Маркетинг для Early Majority до перехода пропасти** — деньги в трубу. Прагматики игнорируют рекламу, верят референсам.

❌ **Игнорировать whole product** — Innovators простят сырость, Early Majority — нет.
