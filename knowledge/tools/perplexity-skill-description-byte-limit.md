# Perplexity: предел описания навыка — 1024 байта, а не знака

## Что происходит

При загрузке навыка (`.zip` с `SKILL.md`) Perplexity отвечает:

```
failed to canonicalize skill artifact: rpc error: code = InvalidArgument
desc = failed to parse skill file: invalid skill description:
description exceeds maximum length of 1024 characters
```

Слово «characters» в сообщении — неправда. **Замер 19.09.2026** по пакету из десяти
навыков:

| Считать | Проходят предел |
|---|---|
| по знакам | 9 из 10 |
| по байтам | 1 из 10 |

Принят был ровно один навык — единственный с описанием короче 1024 **байт** (967).
Три отклонённых укладывались в 1024 знака и всё равно не прошли.

## Почему

В отказе виден Go-сервис (`rpc error`), а в Go `len(строки)` — длина в байтах.
Кириллица в UTF-8 — два байта на букву. Значит для русского описания потолок
**около 512 знаков**, для английского — около 1000.

Замер делается одной строкой:

```bash
python3 -c "print(len(open('SKILL.md').read().split('description:')[1].split(chr(10))[0].encode()))"
```

## Как обойти, ничего не выбросив

Ключевые слова, которые не влезают в `description`, переносятся в поле
**`when_to_use`**. Claude Code учитывает его при отборе навыка наравне с описанием
(общий предел там 1536 **знаков**), а приёмная сторона его просто не читает.

```yaml
---
name: gost-19-komplekt
description: "Использовать, когда … GOST 19 document set."   # ≤1024 байт
when_to_use: "Ключевые слова: состав комплекта ЕСПД, ведомость документов, …"
---
```

Ни одно ключевое слово не теряется, и текст живёт в одном месте — подменять
описание при сборке архива не нужно.

> ⚠️ **Только если навык не уезжает в claude.ai.** `when_to_use` — расширение Claude Code.
> claude.ai, Skills API и `package_skill.py` допускают в шапке лишь `name`, `description`,
> `license`, `compatibility`, `metadata`, `allowed-tools` и на любом другом поле падают:
> «Unexpected key(s) in SKILL.md frontmatter: when_to_use». См. раздел ниже.

## Дополнение 2026-11-02: шапка, годная и для Perplexity, и для claude.ai

Проверка валидатором Anthropic (`quick_validate.py` из навыка skill-creator) показала:
навыки `~/NSU-AI-SKILLS` и `~/PROMPT-Professor` с полем `when_to_use` claude.ai не примет.
Пересечение требований обеих сред:

* описание — до **1024 байт** целиком, ключевые слова — в нём самом (русское описание
  около 480 знаков плюс английские ключевые слова однобайтовые);
* в шапке — только шесть полей спецификации; значения — одной строкой в двойных кавычках;
* сторож проверяет и байты, и состав полей.

Так сделан `~/PRECONSTRUCTION` (версия 1.1.0, `tools/check.py`). Подробно — урок
[when-to-use-breaks-claude-ai-upload.md](../lessons/when-to-use-breaks-claude-ai-upload.md).

## Два других предела той же среды

* **100 файлов на архив** — не жмёт даже для навыка с образцами (самый крупный
  в пакете — 31 файл);
* **5 файлов за отправку** — это предел **одной отправки**, а не пространства.
  Десять навыков грузятся двумя заходами. Проверять стоит: по сообщению
  «Достигнут лимит загрузки» это неочевидно.
