# knowledge/skills/

«Skill» = **конкретный рецепт** с самодостаточным кодом. По сути это
очищенные от проектной специфики версии твоих `SKILL-NN-*.md` из
`~/<PROJECT>/`.

> Эталон формата уже у тебя есть — посмотри `../../SKILL.md` (RAGRAF) и
> `~/GONKA/SKILL-01-idea.md … SKILL-09-demo-mode.md`. Здесь — обобщённые
> версии без RAGRAF/GONKA-специфики.

## Доступные skills

- [discovery-interview.md](discovery-interview.md) — **структурированный
  опрос перед стартом проекта**. Когда Олег говорит «у меня идея —
  давай сделаем X», агент должен прочитать этот skill и провести
  интервью по 3 волнам с pushback'ом из базы накопленных уроков.
- **[ski-coding.md](ski-coding.md)** — **методология соло-разработки с LLM**.
  Чередование текст (md) ↔ код (commit) в цикле из 6 шагов. Ноу-хау
  Олега, зафиксированное в RAGRAF за 8+ итераций. Применять во ВСЕХ
  активных проектах категорий A и B.
- **[preconstruction-research.md](preconstruction-research.md)** — **пресейл-исследование
  идеи многопоточными агентами**. Указатель на Claude Code скиллы `preconstruction-ru`/`-en`
  в `~/PRECONSTRUCTION`: диалог → параллельные потоки-агенты → адверсариальный аудит →
  единый отчёт с питчем и вердиктом «нужен ли ИИ ВНУТРИ». Код в проекте; здесь — когда/зачем/как.

## Когда сюда писать

Ты решил конкретную микро-задачу таким способом, что хочется применить ещё
раз. Например:

- Drag-and-drop из палитры на canvas в React Flow.
- Optimistic mutation с откатом в TanStack Query.
- DuckDB как локальный store + threading.RLock.
- SHACL-bridge: домен ↔ Turtle.
- Подъём FastAPI + React + Vite за 10 минут с нуля.

## Шаблон

См. [../../templates/skill.md](../../templates/skill.md).

Минимум:
1. **Когда применять** — триггер.
2. **Как** — код, который можно скопировать.
3. **Почему именно так** — обоснование и отвергнутые альтернативы.
4. **Подводные камни** — где сломается.
5. **Откуда** — ссылка на проект-источник.

## Чем skill отличается от pattern

См. [`../patterns/README.md`](../patterns/README.md) — таблица сравнения.

Коротко: skill — это «вот код, копируй»; pattern — это «вот идея, реализуй
по-разному».

## Чем skill отличается от lesson

- **Skill** — что делать. Решение.
- **Lesson** — чего не делать. Антипаттерн + причина.

Если одна история и про то и про то — раздели на две заметки и свяжи их.
