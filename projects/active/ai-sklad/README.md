# AI-SKLAD

> **Где код:** `~/AI-SKLAD/`
> **Прод:** статическое демо на Vercel + локальный stateful-сервер с drag&drop CSV
> **Что это:** ИИ-Аналитик остатков — классификация SKU по 7 меткам,
> генерация рекомендаций «товар → действие → срок → эффект», ROI-сравнение
> «без ИИ» vs «с ИИ».

## Зачем

Сокращение времени аналитика логистики с **2-4 часов до 15-30 минут**
в день за счёт автоматической классификации SKU и конкретных
рекомендаций.

**Главная метрика:** ≥ 70% рекомендаций аналитик подтверждает на
горизонте 50+ решений за 4 недели пилота.

## Что отличает

Работает локально как stateful-сервер (drag&drop CSV) **и** в облаке
как статический сайт (4 пресета без upload). Без внешних зависимостей —
чистый Python 3.10+, без ML-библиотек (rule-based v0.1).

## Стек

- **Backend:** Python 3.10+ (без внешних зависимостей)
- **Frontend:** статический HTML + JS, drag&drop через FileReader API
- **Deploy:** Vercel (build статики через `python3 demo/build_static.py`)
- **Локально:** `python3 server.py` → `http://localhost:8765`

## Главные ценности AI-SKLAD для других проектов

1. **IDEA.md как эталон**. 6 вопросов — `[01-idea-formalization]`:
   - Кто пользователь?
   - Какую конкретную задачу?
   - Как решают сейчас?
   - Как проверим пользу? (метрика)
   - Что НЕ делаем? (10 пунктов антископа)
   - Бюджет времени и ресурсов
   + Закрывающий блок «Подтверждение жизнеспособности»

2. **`SKILL-AI-PLAYBOOK.md` vs `SKILL-inventory-ai-demo.md`** —
   разделение «общий рецепт» и «применение в этом проекте». Хороший
   паттерн.

3. **`glossary.md`** — образец словаря **для всех аудиторий** (заказчик,
   аналитик, разработчик). Источник для [concepts/](../../../concepts/).

4. **Деплой статики из Python** — `build_static.py` пре-просчитывает
   все 4 пресета в HTML. Удобный паттерн для «демо для рассылки».
