# АРХИ — платформа контроля регламентов на стройке

> **Где код:** `~/ARCHI-NSU/`
> **Витрина:** <https://archi-nsu.vercel.app/> · **Изделие:** локально, `start.command` / `start.bat`
> **Статус:** active. Первый коммит 2026-09-10.

## Зачем

У заказчика есть система управления проектами **Plan-R** с графиками работ
по объектам строительства. Данные в ней есть; **решения по ним не принимаются** —
никто не открывает график, пока не случится разговор. Замер по боевому портфелю
19.09.2026: давность графиков **1 … 296 суток**, 1 057 слепых суток по портфелю
из двенадцати объектов.

АРХИ — **надстройка**, а не замена: она читает, сводит к величинам своего словаря,
применяет регламенты и пишет ответственному в мессенджер. Обратной записи
в систему-источник нет намеренно (см. `docs/POZICIYA-NADSTROYKI.md`).

## Что внутри

| Часть | Объём на 2026-09-19 |
|---|---|
| Регламенты (правила с порогами, файлами) | 4 |
| Словарь величин — единственное место определений | 18 |
| Страницы | 6: витрина, стройпортфель, регламенты, администратор, документация, описание интерфейса |
| Программный интерфейс | 32 точки `/api`, из них 9 пишущих |
| Таблицы базы | 9 |
| Набор проверок | 862 варианта в трёх пакетах (дымовой 13, полный 839, боевой 10) |

Замеры воспроизводятся: `python -m scripts.opis_teksta`, `python -m scripts.tep`,
`pytest --collect-only -q`. Каждое число в документах несёт команду, которой получено,
и **сторожится проверкой**, которая роняет прогон при расхождении.

## Стек

| Слой | Технология |
|---|---|
| Backend | Python 3.12 + FastAPI + SQLite (WAL) |
| Frontend | **Ванильные HTML/CSS/JS без сборки** — намеренное отклонение от ADR-001 |
| Мессенджер | aiogram (Telegram); 4 команды, 6 действий кнопок |
| Источник данных | Plan-R (чужая действующая система), через защищённый канал |
| Запуск | `start.command` (macOS) / `start.bat` (Windows), одно меню на 7 пунктов |

**Почему не React:** изделие сдаётся комиссии и уезжает архивом на чужую машину,
где не должно быть ни сборки, ни `node_modules`, ни сети. Страница обязана
открываться из файла. Отклонение от [ADR-001](../../../docs/decisions/adr-001-default-stack.md)
осознанное; ADR на него не заводился — стоит завести.

## Документация — комплект ЕСПД по ГОСТ 19

**Одиннадцать документов из одиннадцати**, обозначение `11710-11710`.
Комплект определяется **реестром изделия** (`app/dokumenty.py`), а не содержимым
каталога: файл, лежащий рядом и в реестре не значащийся, не считается нашим
текстом и не уезжает в поставку.

| Код | Документ |
|---|---|
| `11710-11710` | Спецификация |
| `-1` | Техническое задание (редакция 7.6) |
| `-12` | Текст программы — опись, объём, контрольные суммы |
| `-13` | Описание программы |
| `-31` | Описание применения |

| `-33` | Руководство программиста |
| `-34` | Руководство оператора |
| `-51` | **Программа и методика испытаний** — девять испытаний И-01…И-09 |

| `-90` | Методические рекомендации по внедрению и обучению |

Отдельной ветвью — **отчёт о НИР** по ГОСТ 7.32-2017 (`docs/NIR/11710-НИР-3`):

журнал испытаний: `app/zhurnal_ispytaniy.py` + печатная форма `scripts/zhurnal.py`.

## Главные ценности АРХИ для других проектов

1. **`docs/SKILL-TEST-DESIGN.md` — навык отбора проверок.** Вынесен в пакет
   `~/NSU-AI-SKILLS/skills/otbor-proverok/`; там же разделён на переносимый
   слой и примеры. Самый ценный раздел — «чего проверка не находит».

2. **Сторожа чисел.** `tests/test_opis_teksta.py`, `test_pmi_chisla.py`,
   `test_skill_chisla.py`, `test_tep.py` роняют прогон, когда документ разошёлся
   с диском. Приём переносится в любой проект с документацией и числами.

3. **Режим показа.** Изделие, посланное архивом **без `.env`**, поднимается,
   наполняет пустую базу из снимка в поставке и **называет режим вслух**:
   данные из снимка, наружу не ходит, правка закрыта. Отказ на этом месте
   получатель читает как поломку изделия.

4. **Двухъярусность приёмки** (ПМИ, п. 5.4): набор проверок отвечает «изделие
   считает верно», приёмка — «требование задания закрыто». Отсюда порядок
   прогонов **3 → 2 → 6**: закрытое требование при красном наборе недопустимо.

5. **Паритет двух лаунчеров под сторожем.** `tests/test_launchery.py`: человек
   на Windows обязан получить то же изделие, что на macOS, а проверить это
   на приёмке нельзя — приёмщик сидит за одной машиной.

## Ограничения, которые нельзя нарушать

- **`.env` с токенами не входит ни в репозиторий, ни в архив поставки.**
  В поставке только `.env.example` с пустыми значениями.
- **Сервер слушает только `127.0.0.1`.** Снаружи к нему не обратиться.
- **Токены наружу не отдаются ни одной точкой** — ни целиком, ни частью, ни длиной.
- **Имя из запроса никогда не становится путём к файлу или именем таблицы.**
- **`docs/vhod/` — входной пакет заказчика.** Читать и цитировать; не править,
  не публиковать, в объём своего текста не засчитывать.
- **Запись в Plan-R** — только в «Восточный филиал (тестовый)».
- **Источник чужого кода — только `~/NSK_OpenData_Bot`** (донор).
- **Telegram не идёт в рекомендации для СИГМЫ** — там MAX и почта.
